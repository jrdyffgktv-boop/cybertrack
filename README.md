# CyberTrack

为 XMUM（厦门大学马来西亚分校）网络空间安全专业设计的学习计划 PWA：每天自动生成「具体到步骤」的学习任务，打卡、看进度、管理课程表，并把提醒导出到 iPhone 日历。

- 计划期：2026-11-23 → 2027-07-23（暑假 2027-07-24 开始）
- 时区：Asia/Kuala_Lumpur（所有日期计算按这个时区）
- 形态：PWA（可添加到 iPhone 主屏，全屏、离线可用），数据只存在本机
- 语言：中文为主，技术术语保留英文

任务完成记录、课时进度、项目任务进度、手动任务、课表与假期改动全部持久化到 IndexedDB（localStorage 作镜像与降级），关掉 App 再打开不会丢。

## 任务是怎么生成的

生成逻辑是纯函数 `generateDay(date, state)`（`src/domain/generator.ts`），不写入数据库，只依赖：日期 + 内容库 + 设置 + 手动覆盖 + 完成记录。因此同一天任何时候重算结果一致。

0. **导入的计划优先**：如果这一天在 `src/data/content/plan-import.ts` 的 `IMPORTED_DAYS` 里（2026-11-23 → 2027-07-23 共 243 天），当天只有一条任务：标题「周主题 · 本日重点」，步骤来自「课外学习内容」与「学后实践任务」，产出取「今日交付：」后的文本；不再走下面的自动生成。下面的规则只用于计划期以外（例如 2027-07-24 之后）。
1. **判定阶段**（`src/domain/phases.ts`）：公共假期 → 休息；考试周 → 考试模式；复习周 → 复习模式；2027-07-24 起 → 暑假；学期内 → 正常；学期之间 → 假期。
2. **当日预算**（`src/domain/budget.ts`）：正常周 60/60/75/75/90/120/60 分钟；复习周 60 分钟×5（只复习课程）；考试周 50 分钟×3（只做题）；学期假期 60×5 + 周六 120（项目）；公共假期 0。
3. **组成**：把预算拆成片段——课程复习（按当天真实课程均分）、课时学习（从内容库按顺序取，完成的课时自动跳过）、项目任务、周日复盘（统计 + GitHub 提交 + 下周 3 个目标）、考试演练。
4. **排时间**：从设置的学习时间窗开始顺序排，遇到课程或已排任务就往后跳，超过 23:00 会标记冲突；手动任务可指定开始时间。任务列表只显示「第 N 项 · 时长」，不显示具体钟点——钟点只用于导出 .ics 和到点提醒。

课时库：阶段 1 Python（31 课）、阶段 2 Linux/网络（29 课）、阶段 3 AI（29 课）、阶段 4 网安实践（28 课），共 117 课；CyberGuard AI 35 个任务。每课都有 3–5 个步骤和一个可验收的产出物。

## 技术栈

- React 19 + TypeScript + Vite 7
- 手写 CSS（深色 iOS 风 + 每屏一套主题色与整屏背景染色：首页青、学习计划蓝、日历黄、运动红、项目紫、我的橙；无 UI 框架、无图表库，图表用 SVG 自绘）
- IndexedDB 持久化（`src/data/db.ts`），Store 用 Context（`src/data/store.tsx`）
- vite-plugin-pwa（Workbox 预缓存，离线打开）
- Vitest 单测（日期/阶段/生成器/ICS/统计/计时/运动/课表解析）

## 本地运行

要求 Node.js 22+。本机 node 不在 PATH 时用仓库自带脚本（会自动找 DSH 运行时里的 node）：

```powershell
# 安装依赖
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\ct.ps1 install

# 开发（手机与电脑同一 Wi-Fi 时，用手机打开终端里显示的 http://<局域网IP>:5173）
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\ct.ps1 dev

# 类型检查 + 生产构建
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\ct.ps1 build

# 单元测试
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\ct.ps1 test

# 预览构建产物
pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\ct.ps1 preview
```

有全局 node/pnpm 时也可以直接用：`pnpm install`、`pnpm dev`、`pnpm build`、`pnpm test`。

## 任务计时（按真实时长打卡）

任务卡左侧是「开始」按钮：点一下开始计时（按钮变成「结束 12:34」），学完再点「结束」，App 会按你真实的用时写入打卡分钟数（不足 1 分钟按 1 分钟）。计时状态存在 `state.running` 里，中途刷新/关掉再打开还会继续计时；已完成的任务再点圆圈就是取消完成。

因为新计划没有「建议时长」，任务卡上不显示分钟数，只显示「领域 · 第 N 项」；统计、周目标、连续天数都用你计时得到的真实分钟计算。

## 运动页（独立统计）

底部第 6 个 Tab「运动」是独立页面（亮红主题），和学习计划完全分开：

- 11 种运动与 MET：跑步 9.8、快走 4.3、骑行 7.5、篮球 6.5、足球 7.0、羽毛球 5.5、乒乓球 4.0、跳绳 11.0、游泳 8.0、力量/健身房 5.0、瑜伽/拉伸 2.5（`src/data/content/sports.ts`）。
- 打卡方式：点项目 → 两个输入框填「小时 + 分钟」→ 打卡；记录存进 `state.exerciseLogs`（日期、项目、分钟），可删除。
- 卡路里：`MET × 体重(kg) × 小时`，体重在运动页顶部改（30–200kg，默认 60），结果四舍五入成千卡。
- 统计：今日分钟/千卡/次数、连续运动天数、本周 7 柱、本月按项目汇总；**不计入**学习周目标、学习连续天数与领域投入。
- 数据结构在 STATE_VERSION 4 引入；从旧版本升级时会清掉旧的「锻炼」学习打卡（`x:` 前缀），学习打卡与课时进度不受影响。
## 首页智能课表（签到 / Moodle / 完整课表）

首页顶部有一张「智能课表」卡，把课表相关操作都收在一起：

- **一键直达上课签到**：打开 XMUM 学生门户 `https://portal.xmu.edu.my/#/Studentpage`。
- **Moodle**：打开 `https://l.xmu.edu.my/login/index.php`。
- 显示当前教学周（按学期起始日推算）、**下一堂课**和倒计时，以及今天的课程与教室。
- **完整课表**：周视图（8:00–20:00 时间轴，横向可滑动）+ 日列表切换，可翻到上一周/下一周；底部「重新上传课表 HTML」和「导出 .ics」。
- **编辑**：按课程分组列出所有时间片，点 × 删除单个时段、点垃圾桶删除整门课、可清空全部或手动加一门课。
- **智能导入课表**：上传教务系统的 `.html`（或粘贴文本），只在本机解析，支持「追加」和「替换现有」。

## 跑步里程（公里）

运动打卡弹层里，选「跑步」会多一个「里程（公里）」输入框（选填）：

- 只填时长也能打卡；填了里程会额外记录距离，并给出**配速**（分钟/公里）。
- 里程会显示在今日记录、本周/本月汇总和按项目统计里，单位公里、保留 1 位小数。
- 其他运动项目不显示里程输入。
- 卡路里仍按 `MET × 体重(kg) × 小时` 估算，里程不参与计算。

## 导入 / 更新你的计划（xlsx）

App 里 2026-11-23 → 2027-07-23 的任务来自仓库根目录的 `XMUM_AI_Cybersecurity_Daily_Plan_2026-11-23_to_2027-07-23.xlsx`，由 `scripts/import_plan.py` 生成 `src/data/content/plan-import.ts`（生成物，不要手改）。

改计划的流程：

1. 编辑 xlsx，保持 sheet 名「Daily Plan」和列顺序：日期 | 星期 | 周次 | 主题单元 | 学期阶段 | 周主题 | 课外学习内容 | 学后实践任务 | 完成状态 | 个人记录。
2. 重新生成（需要带 `openpyxl` 的 Python，DSH 自带 Python 已装好）：
   ```powershell
   $env:PYTHONIOENCODING='utf-8'
   & "C:\Users\Lucas\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" .\scripts\import_plan.py
   ```
3. `pwsh -NoProfile -ExecutionPolicy Bypass -File .\scripts\ct.ps1 build` 重新构建、重新部署。

转换规则：一天一条任务；标题取「周主题 · 本日重点」；步骤 = 「内容：…」+ 学后实践拆句（按 `；` / `。` / `，` 拆，`并/再/也/且/然后` 开头的片段并入上一条）；产出取「今日交付：」后面的文本（没有就用阶段默认语）；领域按周主题与当天内容的关键词判断（project / ai / python / security，复习周和考试周记为 review）；xlsx 没有时长列，所以 `minutes` 记 0，真实时长由 App 内「开始 / 结束」计时得到。

> 结构升级说明：`STATE_VERSION` 现在是 4。从旧的 65 模板计划（v1/v2）升级时会自动清空旧的打卡、课时进度和项目进度——那些任务 id 已经不存在了；v4 还会把「锻炼」从学习任务里拆到独立运动页，并清掉旧的锻炼打卡。课程表（含教室）、设置和手动任务都会保留。想手动清也可以点「我的 → 清空学习进度」。

## 部署到 GitHub Pages

1. 新建 GitHub 仓库，推送到 `main`。
2. 仓库 Settings → Pages → Source 选「GitHub Actions」。
3. 推送到 `main` 后 `.github/workflows/deploy.yml` 会自动构建并发布到 `https://<用户名>.github.io/<仓库名>/`。

手动构建到子路径：

```powershell

```

## 在 iPhone 上使用

1. Safari 打开部署地址（必须 Safari，Chrome 不能添加到主屏）。
2. 底部「分享」→「添加到主屏幕」→ 添加。
3. 打开主屏图标即为全屏 App；首次打开后断网也能用（Service Worker 已缓存）。
4. 数据只在这台手机：换机前用「我的 → 导出备份」保存 JSON，新机再导入。

### 提醒（重要）

> 任务卡只显示「第 N 项」，不显示钟点也不显示建议时长；具体钟点（默认从学习时间窗起排）只在导出 .ics 与到点提醒时使用，想改就在任务弹层里改「开始时间」。

iOS 的限制：**网页/PWA 被切到后台或关掉后，不能执行本地定时任务**，所以「到点响铃」不能只靠网页。CyberTrack 的做法：

- **推荐**：「我的 → 导出今日/本周 .ics」→ 在 iPhone 文件里点开 → 用「日历」导入。事件里带 `VALARM`，到点由系统日历真响铃，离线也有效。考试周自动把提前量缩短成 10 分钟。
- **App 内**：授权通知后，App 在前台或刚回到前台时会弹系统通知（`Notification` + Service Worker），每个任务到开始时间前提醒；每晚按设定的时间提醒检查完成情况。
- **Web Push**：iOS 16.4+ 支持添加到主屏后的网页推送，但需要服务端（VAPID + Worker）且不保证送达，未纳入 MVP。

## 数据与安全

- 无账号、无后端、无网络请求；课表、打卡、笔记全部在本机 IndexedDB。
- 「我的 → 清空数据」会恢复到初始状态，不可撤销。
- 导出 JSON 是可读备份，注意不要提交到 GitHub。

## 已知限制 / 后续

- iPhone 后台提醒依赖系统日历（.ics），App 内提醒只在前台有效；Web Push 待做。
- 运动记录没有「到点提醒」，也不会导出到 .ics：它是独立的自愿打卡，不排进日程。
- 统计图表以近 7 天和月视图为主，未做年度热力图。
- 课程表按学期维护：换学期后可以在「我的 → 课程表 → 智能导入课表」上传新学期的教务 .html（可追加或替换），也可以逐门手动改。初始课表只录入了 2026 September 学期。
- 2027 年部分宗教节日日期可能微调，已在「我的 → 公共假期」支持增删。
- 后续项目（AI NIDS、独立钓鱼邮件检测器、LLM 安全测试框架）已列在项目页，暂未排期。

## 常用操作

- **改今天的任务**：学习计划 → 点任务卡片右侧箭头 → 改标题/步骤/时长/开始时间/提醒（自动任务会转成「已调整」覆盖，原始任务不再重复出现）。开始时间只用于导出日历和提醒，界面上不显示。
- **加一个任务**：学习计划 → 「在这天加任务」（首页也可以直接「加一个任务」）。
- **看别的周**：学习计划 → 标题右侧的 ‹ › 切上一周/下一周，或点「回到今天」。
- **记一次运动**：底部「运动」→ 点一个项目（跑步/篮球/羽毛球…）→ 填小时和分钟 → 打卡。卡路里按 `MET × 体重 × 小时` 估算，体重在运动页顶部改；今日/本周/本月统计自动更新，学习统计不受影响。
- **智能导入课表**：我的 → 课程表 → 「智能导入课表」→ 上传教务导出的 .html 或直接粘贴文本 → 选「追加」或「替换现有」→ 导入。解析只在本机进行，不上传任何东西。
- **换课程时间 / 教室**：首页当天课程、学习计划、日历的当天课程卡，点课程右侧箭头直接改时间与地点；也可以在「我的 → 课程表」里改。改完首页、学习计划、日历、任务排期一起同步（任务不会排在课程时间内）。
- **加一天休息**：我的 → 公共假期 → 选日期填名称。
- **导出提醒**：我的 → 提醒 → 导出今日/本周 .ics。
